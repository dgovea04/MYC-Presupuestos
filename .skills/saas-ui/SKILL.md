# SaaS UI Skill

Use this skill when building:
- SaaS pages
- dashboards
- settings pages
- pricing pages
- landing sections
- data tables
- UI components

---

# Style Direction

Inspired by:
- Linear
- Stripe
- Retool
- Vercel
- Notion

The UI should feel:
- premium
- minimal
- spacious
- technical
- modern

---

# Layout Rules

Use:
- max-width containers
- generous spacing
- grid layouts
- responsive design

Avoid:
- cramped sections
- oversized shadows
- visual clutter

---

# Card Rules

Cards must:
- use rounded-2xl
- have soft shadows
- have subtle borders
- use white backgrounds

Hover states should be subtle.

---

# Table Rules

Tables should:
- feel modern
- support compact layouts
- resemble modern spreadsheet UX

Use:
- sticky headers when useful
- soft borders
- muted backgrounds

---

# Buttons

Primary:
- blue background
- white text

Secondary:
- light border
- white background

Ghost:
- transparent

---

# Shadows

Use soft shadows only.

Avoid harsh elevation.

---

---

# Responsive

Always mobile-first.

Layouts must adapt cleanly to:
- mobile
- tablet
- desktop

---

# Sections

Landing sections should:
- have visual rhythm
- alternate layouts
- maintain spacing consistency

---

# Motion

Animations should be subtle.

Use:
- fade
- slide
- soft hover transitions

Avoid:
- flashy effects
- bouncing animations
