# Landing Page Skill

Use this skill when building marketing pages.

---

# Landing Structure

Preferred order:

1. Navbar
2. Hero
3. Features
4. Product Preview
5. Benefits
6. Comparison
7. Testimonials
8. Pricing
9. Final CTA
10. Footer

---

# Hero Rules

Hero sections must:
- communicate value immediately
- contain strong headline
- contain concise subheadline
- include clear CTAs

Hero visuals should:
- show product UI
- avoid stock photography

---

# CTA Rules

Primary CTA:
- visually dominant

Secondary CTA:
- less prominent

Use action-oriented text.

---

# Features Section

Use:
- icon cards
- concise descriptions
- clean grid layouts

Avoid:
- large paragraphs
- crowded cards

---

# Product Preview

Always showcase:
- dashboard UI
- tables
- metrics
- workflows

Use mockups built with code.

Avoid external screenshots unless necessary.

---

# Comparison Sections

Use:
- clean comparison tables
- checkmarks
- subtle highlights

Avoid:
- excessive marketing language

---

# Testimonials

Testimonials should:
- feel believable
- be concise
- highlight practical benefits

---

# Pricing

Pricing cards should:
- be simple
- easy to compare
- visually balanced

Highlight the recommended plan subtly.

---

# Footer

Footers should:
- contain navigation
- include company info
- maintain clean spacing

---

# Visual Style

Landing pages should feel:
- premium
- spacious
- modern
- conversion-focused

---

# Animation

Use subtle reveal animations only when useful.

Avoid excessive motion.
