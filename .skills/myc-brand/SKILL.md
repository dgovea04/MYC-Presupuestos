# MYC Brand Skill

This project is MYC Presupuestos.

It is a modern construction budgeting SaaS platform.

---

# Brand Personality

The brand should feel:
- professional
- technical
- trustworthy
- modern
- efficient
- clean

---

# Audience

Target users:
- civil engineers
- contractors
- technical offices
- construction companies
- project managers

---

# Brand Tone

Tone should be:
- clear
- professional
- concise
- modern

Avoid:
- corporate fluff
- startup buzzwords
- exaggerated claims

---

# Tagline

“Plataforma moderna de costos y presupuestos de obra.”

---

# Brand Positioning

MYC Presupuestos modernizes:
- budgeting
- APU workflows
- construction cost management

The product replaces:
- disorganized spreadsheets
- outdated legacy software
- fragmented workflows

---

# Logo Direction

Simple geometric logo.

Use:
- ascending bars
- construction-inspired geometry
- blue gradients

The logo should feel:
- modern
- scalable
- minimal

---

# Visual Identity

Use:
- clean whitespace
- modern typography
- blue accents
- subtle gradients

Avoid:
- heavy industrial aesthetics
- dark cluttered interfaces

# UX Direction

The product should feel:
- faster than Excel
- simpler than enterprise software
- modern and intuitive

---

# Messaging Examples

Good:
- “Presupuestos más rápidos y precisos.”
- “Controla costos con claridad.”
- “Diseñado para ingenieros modernos.”

Avoid:
- “Revolucionario”
- “Disruptivo”
- “Game-changing”
