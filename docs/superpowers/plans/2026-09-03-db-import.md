# Importador de archivos `.db` - Plan de implementacion

> **Para agentes de implementacion:** ejecutar este plan despues de leer `docs/superpowers/specs/2026-09-03-db-import-design.md`. Mantener las casillas actualizadas durante la implementacion.

**Objetivo:** incorporar un importador de bases SQLite `.db` que permita subir el archivo o leer una ruta local accesible por el proceso Node, genere un draft revisable y reutilice la persistencia S10 para crear el proyecto en MC.

**Especificacion:** `docs/superpowers/specs/2026-09-03-db-import-design.md`

**Estado:** Implementado y verificado con pruebas enfocadas. La suite global conserva fallos preexistentes no relacionados en Khipu, review-intelligence, account, usage y AI-agent.

**Referencia funcional:** `docs/superpowers/plans/2026-08-23-delphin-sqlite-import.md`, `components/imports/delphin-sqlite-importer.tsx`, `lib/delphin/sqlite-reader.ts` y la fixture `presupuesto-ejemplo/db/PAVIMENTADO RIGIDO DE LA CALLE _28 DE JULIO_.db`.

## Restricciones globales

- No usar `any`.
- Mantener TypeScript strict.
- No modificar la base `.db` de origen.
- Usar `better-sqlite3` solo en servidor Node y en modo `readonly`.
- Cargar el modulo nativo dinamicamente en route handlers locales.
- No tratar una ruta absoluta enviada por un navegador como si fuera accesible desde un servidor remoto.
- Mantener la lectura, el mapeo y los calculos fuera de UI.
- Usar `decimal.js` para parciales, APUs, totales y pies.
- Validar firma, schema, tamano y relaciones antes de persistir.
- Reutilizar `S10SnapshotContract`, `lib/s10/import-preview.ts` e `importS10SnapshotToMyc`.
- No romper S10, RW7, Delphin, MCP ni PDF.
- No persistir automaticamente al generar preview.
- No registrar contenido completo de la base ni rutas sensibles en logs.

## Resultado esperado

```text
Importaciones > Archivo .db
       │
       ├── Subir archivo
       │      └── POST /api/imports/db/draft (multipart)
       │
       └── Buscar base local
              ├── GET /api/imports/db/local/projects?path=...
              └── POST /api/imports/db/local/export

       └── Snapshot normalizado
              ├── POST /api/imports/s10/draft
              └── POST /api/imports/s10/import
```

## Riesgos y mitigaciones

- **El `.db` no es una variante del schema esperado:** detectar tablas y columnas antes de extraer; devolver incompatibilidad clara.
- **El navegador no puede entregar una ruta absoluta util al servidor remoto:** separar estrictamente upload de ruta local.
- **Archivo bloqueado por otra aplicacion:** abrir readonly y mostrar instruccion de cerrar el programa que lo usa.
- **Schema cambia entre versiones:** versionar el detector/adaptador y registrar schema detectado.
- **APU incompleto o relaciones rotas:** warnings por entidad, sin inventar valores.
- **Perdida de precision:** usar `decimal.js` en todos los calculos financieros.
- **Archivo grande:** limitar tamano/filas y evitar duplicacion innecesaria de buffers.
- **Carga nativa en Next:** runtime Node, import dinamico y prueba de build/typecheck.
- **Duplicacion de persistencia:** converger a `S10ExportSnapshot` y reutilizar `importS10SnapshotToMyc`.
